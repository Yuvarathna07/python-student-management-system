# Student Management System

A menu-driven student record management project built with Python and OOP.

## Features

- Add student records
- Display all students
- Search for a student by name
- Delete a student record
- Update student details

## Student Details

Each student record stores a name, age, course, and marks.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   student project.py


   Note
